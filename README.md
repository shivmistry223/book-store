# Bookstore

An independent bookstore website showcasing fiction, nonfiction, and staff picks with a community events section for readings and book clubs.

Built with semantic HTML5 and modern CSS3 — no frameworks, no dependencies.

## Features

- 📚 **Product Grid** - Responsive grid layout for books organized by category
- 📖 **Book Categories** - Fiction, Nonfiction, and Staff Picks sections
- 🎤 **Events Section** - Upcoming readings and book club meetings
- 📱 **Fully Responsive** - Works seamlessly on mobile, tablet, and desktop
- ♿ **Semantic HTML5** - Proper landmark elements and accessibility
- 🎨 **CSS Variables** - Custom color system for easy theming
- 📐 **Modern Layout** - Flexbox and CSS Grid implementation
- 🔗 **Navigation** - Working internal navigation links
- 📦 **Zero Dependencies** - Plain HTML5 and CSS3, no frameworks
